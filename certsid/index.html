The Cyber Kill Chain (Intrusion Stages)

Step 1
Recon
Planning, Identification, Harvesting email addresses.
Step 2
Weaponize
Coupling exploit with backdoor into deliverable payload.
Step 3
Deliver
Transmitting weaponized bundle to victim (e.g., Email).
Step 4
Exploit
Triggering the code vulnerability on the target system.
Step 5
Install
Installing malware/backdoor for persistence.
Step 6
C2 & Act
Command & Control channel established; Intruder takes action.

Cryptographic Systems

Cryptography transforms readable data (Plaintext) into unreadable data (Ciphertext) using a Key. Modern systems are split into Symmetric (Shared Key) and Asymmetric (Public/Private Key pair).

Identity & Trust Services

Authentication verifies identity (Who are you?). Certificates and PKI create a chain of trust to validate those identities in a digital space.

Secure Password Storage

Never store plaintext. Use Salt + Hash to prevent Rainbow Table attacks.

User Input: "password123" → Do NOT Store
Hash("password123") → Vulnerable (Rainbow Tables)
Hash("password123" + Salt) → Secure Storage
