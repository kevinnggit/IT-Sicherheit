Notiz:

Das System wird von internen Hosts auf dem Port 31337 angepingt. Da auf unserem Host der Port geschlossen ist (ICMP Unreachable Antworten),
kommt keine Verbindung zustande. Es handelt sich vermutlich um einen Scan oder den Versuch einer Malware/eines Spiel-Clients, einen Server
zu finden ("Service Discovery"). Um das "Rauschen" (die ICMP-Fehlermeldungen) zu stoppen und potenzielle Sicherheitsrisiken zu minimieren,
sollte dieser Port durch eine Firewall blockiert werden, damit der Server nicht mehr antwortet.
